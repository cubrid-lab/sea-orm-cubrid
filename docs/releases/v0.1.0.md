## v0.1.0 (2026-03-17)

Initial asynchronous SeaORM integration for CUBRID using SeaORM's proxy database interface.

### Compatibility

- The tagged package declares Rust 1.70 and SeaORM v1 dependencies. This release targets a proxy-backed asynchronous CUBRID connection rather than claiming an unqualified native SeaORM driver implementation.
- The historical release reported 38 tests and full measured coverage. That reported unit-test coverage alone does not establish interoperability with every live CUBRID broker or SQL type.

### Features

- Implement the SeaORM `ProxyDatabaseTrait` integration for a CUBRID connection by @yeongseon
- Add asynchronous CRUD execution and transaction begin, commit and rollback by @yeongseon
- Map common SeaORM values and CUBRID column types for the proxy layer by @yeongseon

### Bug Fixes

- Resolve a connection-lifetime issue before the initial tag ([cc66dc2](https://github.com/cubrid-lab/sea-orm-cubrid/commit/cc66dc2569)) by @yeongseon
